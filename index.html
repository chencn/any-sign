Anyrouter Gateway

HTTP Request Gateway Service

ℹ️ 关于此服务

提供 HTTP 请求中继服务，帮助客户端访问目标 API。所有请求保持原始格式不变。

📖 使用方式

  1. 将 HTTP 请求发送到此服务地址
  2. 支持 GET/POST/PUT/DELETE 等所有标准方法
  3. 自动处理并返回目标服务器响应

💻 示例代码

GET 请求 
curl http://localhost:7860/api/user/self
POST 请求 
curl -X POST http://localhost:7860/api/data \
  -H "Content-Type: application/json" \
  -d '{"key": "value"}'

✨ 特性说明

  • ✓ 支持所有 HTTP 方法（GET/POST/PUT/DELETE/PATCH...）
  • ✓ 保留原始请求头和请求体
  • ✓ 自动处理，客户端无感知
  • ✓ 简单易用，仅需更换请求地址
